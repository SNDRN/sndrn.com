# sndrn.com

Website for [sndrn.com](https://sndrn.com).

## Write a post

```sh
npm ci
npm run new -- "Post title"
npm run preview
```

Set `draft: false` and push to `main`.

## Contents

- `index.html` — homepage
- `posts/` — posts and images
- `brand/` — brand kit
- `scripts/` — build, preview, new post

## Brand kit

Mark, wordmark, lockups and icon in `brand/`, as SVG and PNG, white and black.
